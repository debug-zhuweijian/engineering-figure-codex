# Prompt Style Reference

## Research Figure Style

Prefer publication-style visual language:

- clean white or light neutral background
- high information density without clutter
- clear left-to-right or top-to-bottom reading order
- short labels
- explicit arrows and data/control flow
- consistent panel naming when panels are used
- restrained color palette with semantic color roles

Avoid:

- marketing poster style
- decorative gradients
- vague stock-art backgrounds
- oversized empty hero composition
- fake data, fake citations, or unsupported claims

## Chinese Labels

For Chinese figures:

- keep labels concise
- preserve common abbreviations such as OCR, RAG, LLM, CTC, EEG, ECoG
- use bilingual labels only when the user asks for bilingual output
- avoid long prose inside diagram boxes

## Prompt Shape

A good final prompt includes:

- figure purpose
- audience
- panel or layout structure
- required components
- arrows and relationships
- label language
- visual style
- negative constraints
