# Workflow Reference

## Concept Mode

Use concept mode for architecture diagrams, algorithm workflows, research method figures, hardware/software schematics, graphical abstracts, and explanatory panels.

The local artifact is a prompt. The image is generated by the Codex Desktop conversation tool when available. The scripts must not call Codex Desktop image generation directly.

Minimum brief fields:

- `title`
- `mode`
- `language`
- `audience`
- `background`
- `must_include`
- `style_constraints`
- `negative_constraints`

## Plot Mode

Use plot mode for exact quantitative figures. Numeric content must come from user-provided data or source-backed local data. Do not infer benchmark values.

The local artifact is a rendered figure plus the plot spec used to generate it.

## Mixed Mode

Use mixed mode when the final figure needs both exact quantitative panels and conceptual panels. Render quantitative panels locally before generating conceptual panels.

## Artifact Boundary

Stable local artifacts:

- brief JSON
- prompt Markdown
- plot spec JSON
- exact plot PNG/SVG/PDF

Conversation artifacts:

- generated conceptual images from Codex Desktop image generation

Do not promise script-level automatic saving for conceptual images unless the current tool explicitly returns a local file path or the user provides an exported image.
